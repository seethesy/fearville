# Puzzle generation authoring

`lib/rite/generator-config.ts` holds the normal defaults, generation budgets, visual skins, clue weights, clue counts, timing constants and four difficulty presets: easy, normal, hard and impossible. “Impossible” means extremely difficult, not unsolvable. Normal maps to the current hard Night Rite defaults (28–32 optimal slides/pours). Night Rite continues using normal; no lobby difficulty picker is added.

Preview offline with `npm run puzzles:sample -- --puzzle=escape --preset=hard --n=50`. Puzzle names: escape, sphinx, lab, ritual. Optional `--seed=review` gives repeatable sample seeds. JSON metrics and up to three HTML examples are written under `work/puzzle-samples/<puzzle>-<preset>/`. Reports include certified optimal moves for Escape/Lab, unique solution count and one-clue-at-a-time solver grade for Sphinx, omen counts for Divination, and elapsed generation/verification time. Failed generations are retained in the report and cause a nonzero exit code; each sample has a 20-second worker budget. Files stay local and ignored by Git.

Board dimensions (6×6), block geometry/layout mix, four liquid layers, five Sphinx entities, relational clue semantics and most wording templates are still contracts shared by generators, solvers, saved-state formats and artwork. The config records structural dimensions but changing those alone is not supported yet. Full structural/wording extraction requires follow-up work; do not imply that editing a dimension already resizes the UI or solver. All existing callers remain on normal, including the certified live puzzle bank. Retune/re-certify the bank with `scripts/generate-rite-bank.mjs` when changing live normal defaults; never hand-edit the generated bank.

Preset changes are offline authoring knobs. Review solver metrics and examples before changing production defaults. Puzzle Rush can consume normal prepared puzzles without running expensive certification on a phone. Higher preset selection in Puzzle Rush belongs to FEAR-171.

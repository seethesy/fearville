# Sound-effect event inventory

Review for Art (FEAR-156). These are candidate IDs, not new event hooks. No behavior changes. Fill in the last three columns; blank means undecided. Includes Storyteller controls as requested. Existing synthesized cues are noted so file-based replacements do not double-play.

Audience means devices allowed to receive that event in their existing player view. “Everyone” never authorizes publishing a hidden night action, private message, role, or unannounced death. Hook playback into a newly observed view transition, not every socket frame/poll, render, optimistic update, or request retry. First load, reconnect snapshots and rewind need explicit deduplication before playback is implemented in FEAR-169. This inventory records source functions, not line numbers that drift.

Frequency is per device. High frequency candidates need throttling or aggregation. The Storyteller hears public cues plus explicitly host-only cues; players hear only their own authorized view.
